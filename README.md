# Overview

Hello World program written in TypeScript showing VS Code integration with TypeScript.

The software prints Hello world on the terminal, asks for the user's name, and then prints Hello followed by that name.

To show my learning and ability to use TypeScript to write a simple application as I keep learning the new language.

[Software Demo Video](https://youtu.be/EBi9OrTQ5yU)

# Development Environment

I used Visual Studio Code to write and run the program. The programming language is TypeScript, which is a superset of JavaScript. This language focuses more on types and type checking, which helps to catch errors early in the development process before moving into production.
